# Portfolio

Implementar el portafolio tomando como referencia el wireframe `portfolio-wireframe.png`.

## Tecnologías

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion

## Objetivos

- Diseño minimalista.
- Responsive.
- Animaciones suaves.
- Código limpio.
- Componentes reutilizables.

## Estructura

- Hero
- Perfil profesional
- Habilidades
- Proyectos
- Experiencia
- Educación
- Contacto

## Navegación

El panel izquierdo es fijo.

Cada icono debe hacer scroll hacia su sección correspondiente.

El icono de la sección visible debe resaltarse.

## Proyectos

Los proyectos se obtienen mediante la API de GitHub.

No utilizar datos estáticos.

Cada tarjeta debe mostrar:

- imagen
- nombre
- descripción
- tecnologías
- enlace GitHub
- demo (si existe)

## Responsive

En móviles el sidebar debe convertirse en un botón tipo menú.
